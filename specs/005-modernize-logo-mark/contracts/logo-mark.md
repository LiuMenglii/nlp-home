# Contract: Logo Mark Asset（最终图标资产契约）

**Feature**: `005-modernize-logo-mark` | **Date**: 2026-10-17（同日修订：三候选工作流；2026-10-20 修订：favicon 验收口径、渲染验收矩阵「背景」档收敛为实际渲染场景；同日迭代 2：三版候选参数升级，色值与圆角按新候选校准；同日迭代 3：三符号恢复（文 / 脑 / 笔 各占一带），绿带统一 42，笔画 2.8 / 3.0） | **Spec**: [../spec.md](../spec.md) | **Model**: [../data-model.md](../data-model.md)

本契约定义**阶段二落位 `public/` 的两份最终 SVG 资产**的可验证形态：`public/logo.svg` = 被选定候选原样落位，`public/favicon.svg` = 由选定候选派生的同源简化版。候选规格与选定流程见 [candidates-review.md](./candidates-review.md)。实现（tasks 阶段）与验收 MUST 逐条满足；契约优先级为 spec > 本契约 > tasks 细节，任何冲突以 spec 为准。

## 1. 交付物

| 资产 | 路径 | 来源 | 变更 |
|------|------|------|------|
| 完整图标 | `public/logo.svg` | 选定候选（SELECTION.md 记录）原样落位 | 替换现有同名文件 |
| 标签页图标 | `public/favicon.svg` | 选定候选的同源简化派生 | 同一次变更内替换 |

两份资产 MUST 在同一次变更中更新（FR-004）；不得出现任一旧版残留或旧引用。favicon MUST 在选定版通过 SC-006 评审后派生，MUST NOT 在候选阶段逐版产出（FR-009）。favicon 无需单独评审——SC-006 不覆盖 favicon，其验收仅按 SC-002 的 16px 口径执行（spec 2026-10-20）。

## 2. 技术格式（两份资产共同，候选阶段即须满足）

- SVG 1.1 纯矢量单文件；`xmlns` 必须声明；无 `<script>`、无事件属性、无 `<foreignObject>`。
- 自包含：无 `<image>`、无 data-URI、无外部 `<use xlink:href>`、无 `@import`/`<style>` 外链、无字体依赖、无位图。
- 无编辑器/导出器元数据（无 draw.io `host`/`content`、无 `xmlns:v`、无 `<metadata>`）。
- 唯一允许的装饰性技术为 `clipPath`（外轮廓圆角；迭代 3 三版候选均使用）；`clipPath` 的 `id` 在文件内唯一。
- 平面填充：无渐变（`<linearGradient>`/`<radialGradient>`）、无滤镜（阴影/发光）、无透明度叠色、无描边滥用（三色色块仅 `fill`）。
- 文件体积目标 ≤ 2KB/份（原型参考：logo ≈ 1.0KB、favicon ≈ 0.5KB）；不是硬门禁。
- 不写 `width`/`height` 属性亦可；若写，MUST 与 `viewBox` 比例一致（4:3 / 1:1）。

## 3. 画布与尺寸

| 属性 | LogoMark | FaviconMark |
|------|----------|-------------|
| `viewBox` | `0 19 140 105`（三版候选均保持） | `-10 -21 160 160`（不变） |
| 内在尺寸 | 140 × 105 | 160 × 160 |
| 宽高比 | 4:3（1.3333）——相对现状变化 **0%**（spec 口径 ≤20%，三版候选均不使用该杠杆） | 1:1 |
| 背景 | 透明（无底色矩形） | 透明 |
| 内容覆盖率 | 宽高均 ≥90%（无裁切、无异常留白） | 方形画布对宽幅标识的规范留白不计入"异常留白" |

## 4. 最终几何与符号（按选定候选执行）

几何（三色路径 / 色带节奏 / 外轮廓圆角 / 右下尖角）、符号系统（形态 / 光学框 / 笔画 / 锚点）与色值，**以 [candidates-review.md](./candidates-review.md) §3–§6 的对应候选规格 + `candidates/SELECTION.md` 记录为准**。落位资产 MUST 与选定候选完全一致（逐字节或仅含无语义的空白/注释差异），并满足以下包络约束：

1. 三枚橙色 → 绿色 → 蓝色、向右延展的箭头形色块，顺序与方向不变，水平构图；相邻色块精确共边、叠绘无发丝状接缝；
2. 右下蓝色箭头尖角点缀存在（可圆角化、可与主体融合，MUST NOT 删除）；
3. 白色辅助符号 1–3 个（选定版为 3：文 / 脑 / 笔，各占一带），完整位于单一色带内，锚点 = 所属色带横截面中点，墨迹到任一分色边界最小距离 ≥ 色带高度 80 的 8%（6.4 单位，亦 ≥ 垂直带宽 32 的 20%；迭代 3 实测最低 A 脑 7.09、B 脑 7.84、C 脑 8.10）；
4. 选定候选参数须在其契约界限内（迭代 3：分界折线 run `w` = 27 / 23 / 21；色带节奏 54/42/44 · 46/42/52 · 42/42/56；外轮廓 r=5 / r=6 / 非对称 r=9·5·3；尖角 r=2.5 / 3 / 3；L/S 偏移 ≤20%；三符号笔画 2.8 / 2.8 / 3.0）。

## 5. 色值

| Token | 候选 a（选定时的取值） | 候选 b（+10% L） | 候选 c（−12% L） | 允许偏差 |
|-------|------------------------|------------------|------------------|----------|
| `orange` | `#f7941d` | `#f8a138` | `#eb8408` | 色相不变；L 偏移 0% / +10.2% / −12.0%；S 偏移 ≤0.3%；硬上限 ≤20% |
| `green` | `#28ae6c` | `#2cbf77` | `#23995f` | 同上（+9.8% / −12.1%） |
| `blue` | `#037ec2` | `#038bd5` | `#036fab` | 同上（+9.8% / −11.7%） |
| `white` | `#ffffff` | `#ffffff` | `#ffffff` | 纯白、无透明度 |

MUST NOT 引入表外颜色、渐变或透明度；c 被选定时，其微调值须在 SELECTION.md 中逐色记录 hex 并可按 HSL 复核偏移 ≤20%。

## 6. favicon 派生规则

- 保留选定候选的三条三色路径与同套轮廓处理（a r=5 / b r=6 / c 非对称 r=9·5·3 + 微调色值），**不含**三个白色辅助符号与右下尖角（沿用 004 简化策略）；
- `viewBox="-10 -21 160 160"` 方形画布、透明底；纯矢量、无字体、无外部引用；
- 16px 下橙/绿/蓝三色可相互区分、向右箭头轮廓可辨；深/浅标签栏背景均可辨（不依赖白色细节）；
- favicon 验收仅按 SC-002 的 16px 口径执行；SC-006 不覆盖 favicon，无需单独评审（spec 2026-10-20）。

## 7. 身份不变量（MUST）

1. 三枚橙色 → 绿色 → 蓝色、向右延展的箭头形色块，顺序与方向不变，水平构图；
2. 至少一处白色辅助符号，表达语言/翻译、认知/大脑、书写/笔中的至少一种语义，且完整位于单一色带内；
3. 右下蓝色箭头尖角点缀存在；
4. 六边形整体轮廓、4:3 画布（宽高比相对现状变化 ≤20%，本设计 0%）、三色色相不变且明度/饱和度偏移 ≤20%；
5. favicon 与完整图标同源（同三色路径、同色值、同轮廓处理）；
6. 新旧并排可辨认为同一标识（SC-001 / SC-006，SC-006 在合入前完成）。

## 8. 禁止项（MUST NOT）

- 改变三色顺序或向右方向；删除尖角；引入新意象或无关图形/文字；
- 引入渐变、阴影、发光、3D、纹理、动效、字体、位图、外链资源；
- 新增顶栏专用小尺寸资产（favicon 的同源简化不在此列）；
- 在资产中混入第三方编辑器元数据；
- 让白色符号跨越色带边界或贴边（低于 §4.3 的安全边距）；
- 修改 `site.json` 路径或新增图标使用场景；
- `candidates/` 评审产物进入 `public/`、`src/` 或构建产物。

## 9. 渲染验收矩阵（选定版 / 最终资产）

| 场景 | 尺寸 | 通过标准 |
|------|------|----------|
| 顶栏 | 高 ≈22px（宽 ≈29px） | 三色边界清晰；白色符号为均匀、有意的点缀，无糊块/脏边/锯齿/裁切 |
| 放大查看 | 64px、128px、256px | 保留的每个白色符号主形态可逐个辨认；圆角与尖角清晰；无变形 |
| 标签页 | 16px、32px | 橙/绿/蓝可相互区分；向右箭头轮廓可辨；透明底在深浅标签栏均可辨 |
| 高 DPR | DPR 2 / 3 | 边缘清晰，无模糊、裁切或变形 |
| 背景 | 白色顶栏（图标的实际站点渲染背景；站点为浅色系、无深色模式） | 图形清晰；白色符号完整落在色带内 |
| 新旧并排 | 大尺寸（≥128px） | 判为"同一标识的现代化版本"（SC-001；SC-006 = 未参与设计的实验室老师同一评审者两项判定均通过，于选定后合入前完成、仅针对完整图标——不覆盖 favicon） |

## 10. 变更协议

- 阶段二替换两份资产时，`site.json` 的 `logo` / `favicon` 路径 MUST 保持不变；`content.config.ts` 的构建期校验 MUST 继续生效（缺失资源即构建失败）。
- `Navbar.astro` 中 `img` 的宽高比回退属性 MUST 为 4:3（40×30，三版候选均保持 4:3 画布）；展示尺寸仍由 `height: 1.2em; width: auto` 决定。
- 替换后 MUST 通过 `npm run check` 与 `npm run build`；MUST NOT 新增依赖、脚本或 CI 步骤。
- 旧资产仅可经 `git show HEAD:public/logo.svg`（及 favicon）取用做并排比对，不得作为仓库文件留存。

## 11. 非目标

- 深色模式、打印、灰度/单色、小于 16px 的尺寸、分享卡片/头像/PWA/触屏图标、动效版本；
- 多配色变体、字标 "CIGMA" 的字体/字距调整、页面布局或颜色变量改动；
- 引入设计工具链、SVGO、图标字体或任何新依赖；
- 对比页/候选文件进入站点交付物（见 [candidates-review.md](./candidates-review.md)）。
