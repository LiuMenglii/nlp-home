## 2. 候选共同规则（三版均 MUST）

1. **身份不变量**（FR-001 全项）：三枚橙 → 绿 → 蓝、向右延展的箭头形色块（顺序与方向不变、水平构图）；1–3 个白色辅助符号（表达语言/翻译、认知/大脑、书写/笔中至少一种语义，完整位于单一色带内）；右下蓝色尖角点缀存在（可圆角化/移位/融合，不得删除）；整体轮廓新旧并排可辨认为同一标识。
2. **放宽口径**：画布 `0 19 140 105`（4:3）三版均保持——宽高比相对现状变化 0%（口径 ≤20%，杠杆不使用）；三色色相不变、明度/饱和度偏移 ≤20%、无渐变——A 逐字 0%、B 统一 +9.8~10.2% L、C 统一 −11.7~−12.1% L（ΔS ≤0.4%）。
3. **格式**：纯矢量自包含，同 [logo-mark.md](./logo-mark.md) §2 全部规则。
4. **三档渲染可行**（FR-003 候选级预检，目视定性判断）：22px 高下三色边界清晰、白色符号为均匀点缀；16px 高下三色可区分、箭头轮廓可辨；64px 高下三个符号主形态可逐个辨认（脑符号以中央裂与两半球辨识）。（候选阶段不逐版量化验收；SC-002 / SC-003 的量化验收仅针对选定版执行——spec 2026-10-20。）
5. **符号系统**：三版均取 3 个白色符号（文 / 脑 / 笔），各占一带、共用 §5 形态定义（A/B 笔画 2.8、C 3.0；光学尺寸 文 17.2×18.3、脑 20.6×15.0、笔 18.7×18.4，C 随笔画等比 +0.2）；锚点 = 所属色带 y=59 横截面中点；墨迹到任一分色边界最小距离 ≥6.4 单位（色带高度 80 × 8%）——实测 A 11.7 / 7.1 / 7.4、B 9.5 / 7.8 / 11.7、C 8.2 / 8.1 / 13.9。
6. **几何构造**：外轮廓六边形 + 两条等角 chevron 分界折线（折线 Δy=40、水平 run = `w`，分界与水平夹角 `atan(40/w)`）；三色叠绘顺序橙 → 绿 → 蓝；圆角只作用于外轮廓（`clipPath`），内部分色边界保持锐利；相邻色块精确共边、叠绘无发丝状接缝。

## 7. 并排对比页（`comparison.html`）

- **单一自包含 HTML**：4 个图标（现状 + A + B + C）以内联 `<defs><g id="…">` 各定义一次、以 `<use href="#…">` 引用渲染；零 JS、零外部请求、系统字体、内联样式；现状图标以创建时的 `public/logo.svg` 内容为内联快照（不运行时引用 `public/` 路径）；三版 `clipPath` id 在页内唯一（`clip-a` / `clip-b` / `clip-c`）。
- **结构**：标题 + 本轮迭代说明 + 评审说明（判定口径 = SC-001 身份不变量清单；三档尺寸关注点）+ 四行（现状 / A / B / C）× 四档渲染（**128px、64px、高 22px、高 16px**；满足 FR-009 三档，另给一档大图）。
- **22px 档**：白色顶栏模拟条（白底 + 底部细边框）。**16px 档**：完整图标缩至 16px 高的模拟渲染，页内注明"favicon 将按选定版派生，此列为等比模拟，非 favicon 资产"。

## 8. 选定与评审工作流（FR-009 / SC-006）

1. **候选自查**（实现阶段）：三版逐项过 §2 共同规则与 §3–§6 各自参数；对比页四行四档渲染正常。
2. **维护者选定**：打开 `comparison.html` 并排评审 → 选定一版 → 记录于 `SELECTION.md`（候选 id、选定人、日期、理由摘要、选定版关键参数与色值快照）。选定依据：身份不变量为硬性门槛，其外的取舍标准（现代感、小尺寸表现等）不作定义，交由维护者裁量；候选评审对 SC-002 / SC-003 仅作目视定性判断（见 §2.4）。
3. **SC-006 外部评审**（仅针对选定版，时点 = 选定之后、合入之前）：评审者为**未参与设计的实验室老师**（≥1 人，由维护者邀请；维护者本人与候选制作方均属"参与设计"，不得担任评审者）；评审者在无提示的并排对照下对"现状 vs 选定版"作出**两项判定**——"同一标识的现代化版本"（而非"另一个标识"）与"更现代、未大改整体设计"；两项判定由同一评审者作出，均须通过；结论记录于 `SELECTION.md`。
4. **通过 → 阶段二**：由选定候选派生 favicon（[logo-mark.md](./logo-mark.md) §6）→ 两份资产 + `Navbar.astro` 回退属性同次落位 → 门禁 / 尺寸矩阵 / 视口回归 / 负向用例（[../quickstart.md](../quickstart.md)）；favicon 验收仅按 SC-002 的 16px 口径执行，SC-006 不覆盖 favicon、无需单独评审。
5. **失败路径 → 迭代候选**：维护者无法从三版中选定任何候选，或选定版未通过 SC-006 → **重新生成三版候选**（迭代后仍 MUST 满足 §2 共同规则与身份不变量）→ 重新进入对比评审与选定流程（重跑第 2 步）→ 仅对新选定版重跑第 3 步（不逐版盲评）；外部评审者不可得、评审者与维护者意见不一致、迭代轮数上限等评审流程异常不定义为需求，由维护者届时裁量（spec 2026-10-20）。**迭代 2 与迭代 3 均按此路径执行**（首轮未选定 → 重锁参数 → 重生成三版 + 对比页；迭代 3 再因"丢失大脑符号"恢复三符号）。

## 9. 禁止项（MUST NOT）

- 对比页或候选文件进入 `public/`、`src/` 或站点构建产物；
- 为对比页引入 JS、外部请求、新依赖或构建脚本；
- 候选阶段产出 favicon 变体；
- 任一候选违反 FR-001 身份不变量或放宽口径上限（宽高比 >20%、L/S >20%、色相变化、渐变）；
- 三版候选之一被直接合入 `public/` 而未走选定 + SC-006 流程；
- 以对比页作为站点页面/路由/图标使用场景（FR-007 豁免仅限评审用途）。
