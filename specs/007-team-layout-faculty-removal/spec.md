# Feature Specification: Team 页学生分组纵向展开、教师移除与成员链接标签（Team Layout, Faculty Removal & Member Link Tags）

**Feature Branch**: `007-team-layout-faculty-removal`

**Created**: 2026-10-23

**Status**: Draft

**Input**: User description: "修改 Team 界面：PhD Candidates 和 Master's Students 不并排。各自占据完整的一行；删除王老师的介绍（包括主页）"

**扩展输入（2026-10-23）**: 在读学生列表增加 HOMEPAGE 标签，与 GitHub 标签、Scholar 标签三选一；补充主页 `https://gccnlp.github.io/`、`https://iie-ycx.github.io/`、`https://qdcassie-li.github.io/`；为在读博士刘曦雨增加 Scholar 标签 `https://scholar.google.com/citations?user=94lNc6oAAAAJ&hl=zh-CN`；新增李雨晴（PhD），入学年份与顾佴彬相同。

## 目标与范围

本特性改动 Team 页（`/team/`）三处：

1. **在读学生分组改为纵向排列**：PhD Candidates 与 Master's Students 两个分组不再并排，各自占据完整的一行（内容区整宽），在所有支持的视口宽度下均保持纵向堆叠。
2. **移除王老师（王伟平）的教师介绍**：其姓名、职称、研究方向、个人简介、邮箱与个人主页链接不再出现在站点人员展示中；同时删除其照片文件 `public/teachers/wang-weiping.svg`，使该照片在站点上不可访问；其余教师信息与排序保持不变。移除后剩余四位教师在宽屏下改为两行两列（2×2）排列。
3. **成员链接标签统一为三选一**：在读学生与毕业生列表的每位成员至多显示一个链接标签（Homepage / GitHub / Scholar）；在读学生列表由「姓名可点击 + 可选 GitHub 标签」改为「姓名纯文本 + 单一链接标签」。数据文件中同一成员至多填写一个链接字段，填写两个及以上时构建失败。本次补齐顾佴彬、杨晨旭的主页展示，新增李雨晴（PhD，入学年份 2022，与顾佴彬相同）及其主页，并为刘曦雨配置其 Google Scholar 主页的 `Scholar` 标签。

教师数据由站点首页与 Team 页共同使用，因此王老师的移除在数据源头生效，两处展示同步一致。论文、新闻、画廊等其余内容不在本次范围内。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 学生分组纵向排列 (Priority: P1)

访客打开 Team 页浏览在读学生时，PhD Candidates 与 Master's Students 两个分组上下排列，每个分组独占完整的一行，分组内的学生列表横跨内容区全宽；任何视口宽度下都不会出现左右并排的两个分组。

**Why this priority**: 这是本次最直观的版面诉求。并排布局在宽屏下使两列间距被拉大、行内右侧留白过多；改为上下两行后可让每个分组的姓名、年级与备注获得统一的横向空间，读起来更像一份连续名单。

**Independent Test**: 在宽屏（≥1280px）与窄屏（<768px，如 375px）打开 Team 页，观察两个分组标题的纵向位置关系：PhD Candidates 在上、Master's Students 在下，二者左右边缘与内容区左右边缘一致，且同一分组内列表横跨整行。

**Acceptance Scenarios**:

1. **Given** 任一支持的视口宽度，**When** 浏览 Team 页在读学生区域，**Then** PhD Candidates 与 Master's Students 上下排列，各自占满整行内容宽度，不出现左右并排。
2. **Given** 任一支持的视口宽度，**When** 对比两个分组的容器，**Then** 两个分组容器的左边缘、右边缘分别对齐（与内容区左右边缘一致）。
3. **Given** 宽屏视口（≥1280px），**When** 浏览两个分组，**Then** 每个分组仍为单列整行，不因空间充足而恢复并排。
4. **Given** 某分组无成员，**When** 浏览，**Then** 该分组仍独占一行并显示既有空状态提示，不出现半宽留白或与另一分组并排。

### User Story 3 - 成员链接标签三选一 (Priority: P2)

访客浏览 Team 页的在读学生与毕业生名单时，每位成员最多看到一个链接标签——Homepage、GitHub 或 Scholar，点击标签在新标签页打开对应页面；成员姓名本身不再可点击。维护者在数据文件中为同一成员填写两个或以上链接字段时，构建失败并指出成员与冲突字段，避免重复入口或错误链接上线。

**Why this priority**: 统一链接入口，避免姓名链接与标签并存造成重复跳转；把「一人一个链接」固化为数据约束，让配置错误在发布前暴露。

**Independent Test**: 打开 Team 页，确认顾佴彬、杨晨旭、李雨晴各显示且仅显示 1 个 Homepage↗ 标签且姓名不可点击；李江楠、张瀚文、郑明钰、刘正宵各显示 1 个 GitHub↗ 标签；刘曦雨显示 1 个 Scholar↗ 标签；季慧山不显示标签；李雨晴出现在 PhD Candidates 且显示 Since 2022。临时在任一成员条目同时填写两个链接字段，构建应失败并指明该成员（验证后还原）。

**Acceptance Scenarios**:

1. **Given** 成员仅填写一个链接字段，**When** 浏览在读学生或毕业生列表，**Then** 仅显示该字段对应的一个标签（Homepage↗ / GitHub↗ / Scholar↗），姓名不呈现为链接。
2. **Given** 同一成员填写两个及以上链接字段，**When** 执行构建，**Then** 构建失败，错误信息指明数据文件、成员姓名与冲突字段。
3. **Given** 顾佴彬、杨晨旭、李雨晴，**When** 浏览在读学生分组，**Then** 三人各显示 Homepage↗ 标签，链接地址分别与 `https://gccnlp.github.io/`、`https://iie-ycx.github.io/`、`https://qdcassie-li.github.io/` 一致。
4. **Given** 李雨晴新增条目（入学年份 2022，与顾佴彬相同），**When** 浏览 PhD Candidates 分组，**Then** 显示其姓名、Homepage↗ 标签与 Since 2022 文案。
5. **Given** 刘曦雨配置了 scholar 链接，**When** 浏览在读学生分组，**Then** 显示 Scholar↗ 标签，链接与 `https://scholar.google.com/citations?user=94lNc6oAAAAJ&hl=zh-CN` 一致，且不显示 GitHub 或 Homepage 标签。
6. **Given** 任一视口宽度（320px–1920px），**When** 浏览两类名单，**Then** 唯一标签不换行、不截断、不溢出，且不与姓名或年份重叠。

### Edge Cases

- **宽屏下分组仍纵向**：即使视口足够宽，两个分组也不得并排；不得因「空间充足」而出现两列。
- **分组为空**：某一分组无成员时仍独占整行，显示既有空状态文案，不与另一分组并排。
- **超长条目**：学生年级或备注较长时，在整行宽度内正常折行收纳，不溢出容器、不截断；成员姓名以 4 个汉字为上限，超长姓名不在本期范围内（作为后续例外单独处理）。
- **教师卡片 2×2**：本次仅变更宽屏排布——≥1280px 下 4 张卡片由 3+1 改为两行两列（2×2）；窄屏行为不变：768–1279px 维持既有两列、<768px 维持单列。MUST NOT 出现每行 3 张、第二行仅 1 张的 3+1 形态。
- **残留资源与链接**：移除后不得残留指向王伟平个人主页的可见链接或引用其照片的展示元素；`public/teachers/wang-weiping.svg` MUST 被删除，构建产物中该路径不可访问。
- **链接字段冲突**：同一成员填写两个及以上链接字段（`url` / `github` / `scholar`）时构建失败；错误信息 MUST 按 `url` → `github` → `scholar` 顺序列出全部冲突字段，不得只显示其中一个而静默忽略其余。
- **最长标签**：`Homepage ↗` 是三种标签中最长的文案（实测 106.11px），标签列 MUST 按其实测宽度预留并在列内居中，不得因一行只有一个标签而压缩到换行或截断；验收基准为 Chrome 最新稳定版 + 站点默认系统字体栈，并在 Windows/macOS 复测。
- **无链接成员**：不渲染标签、不留占位，行内姓名与年份照常对齐。
- **失效或非 HTTPS 链接**：任何链接字段不是合法的 `https://` 地址时，按既有数据校验使构建失败，不渲染不可用标签。
- **姓名链接移除**：杨晨旭原姓名链接改为 Homepage 标签后，不得残留重复的姓名链接入口。
- **窄屏行序**：堆叠态（视口 ≤479.98px）下，姓名与年级同行、备注随后自然换行、标签恒为最后一行，标签左边缘与姓名左边缘同线。
- **无年级成员**：`grade` 为空时不渲染 Since 文案、不保留空占位；刘曦雨本期即为此状态（年级待核实，数据删除后归入名单末尾的无年级分组）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Team 页的 PhD Candidates 与 Master's Students 两个分组 MUST 在所有支持的视口宽度下上下排列，任一分组 MUST NOT 与另一分组左右并排。
- **FR-002**: 每个分组 MUST 占据内容区整行宽度；两分组容器的左、右边缘 MUST 分别与内容区左右边缘对齐。
- **FR-003**: 分组顺序 MUST 保持 PhD Candidates 在前、Master's Students 在后。
- **FR-004**: 分组内学生条目的既有排布规则（姓名居左、年级与备注靠右、上下分隔线、左右内距、跨区块列对齐）MUST 保持现状，不因本次布局调整而改变（FR-019 在 US3 中对姓名列与标签列宽的调整除外）。
- **FR-005**: 两个分组之间的纵向间距 MUST 不小于 32px，避免两组名单视觉粘连。
- **FR-006**: Team 页 Faculty 区块 MUST NOT 展示王伟平的任何介绍内容，包括姓名、职称、研究方向、简介、邮箱与个人主页链接。
- **FR-007**: 站点首页人员区块 MUST NOT 展示王伟平的任何介绍内容（与 FR-006 同一数据来源，展示保持一致）。
- **FR-008**: 移除王伟平后，其余教师卡片的姓名、职称、研究方向、简介、邮箱、个人主页链接与相对顺序 MUST 保持不变。
- **FR-009**: 移除后 Faculty 区块 MUST 自然收拢，MUST NOT 出现空白占位、破损卡片或残留的失效链接；四位教师卡片在 ≥1280px 视口下 MUST 以 2×2（两行两列）等宽排列。
- **FR-010**: 全站渲染页面（`/`、`/team/` 及其余全部页面）的可见内容及构建产物 HTML MUST NOT 残留指向王伟平个人主页的可见链接或其介绍文本；历史规格文档（`specs/`）不属于站点内容，不在本约束范围。
