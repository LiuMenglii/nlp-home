# Contract: Team 页布局行为（team-layout）

**Date**: 2026-10-12（rev2：纳入五列布局、链接列、FR-012 排序与 FR-004 适用范围拓展；rev3（同日第三轮用户裁定）：Graduates 满宽形态、混合对齐口径与无外链行豁免） | **Spec**: [spec.md](../spec.md) | **消费方**: Team 页实现与验收（quickstart.md）、主页回归验证

本特性对外契约对象有二：① **Team 页（/team/）的布局行为**——"UI 契约"（界面在不同视口下 MUST 呈现的排布规则），也是后续任何样式改动的回归基线；② **维护者数据契约的最小扩展**（`students` / `graduates` 新增可选 `github` 字段 + 学生 `url→github` 迁移（已合入）+ `graduates` 新增可选 `url` 字段与三条已核实取值（rev2），字段约定见 [data-model.md](../data-model.md)）。

## 1. 视口行为矩阵（MUST）

| 视口 | Faculty 教师网格 | 在读学生分组 | Graduates 列表 |
| ---- | ---- | ---- | ---- |
| ≥ ~900px（含 1024 / ≥1280 验收档） | 两列（每列 ≥420px，恰好容器不足时自动单列） | 两组并排（PhD 左 / Master 右，每组 ≥320px） | **五列对齐生效**：姓名 / 学位 / 毕业年份 / 去向 / 链接各对齐到一致的列位置 |
| 768px | 单列（轨道贴合容器宽度） | 两组并排或堆叠由容器宽度自然决定（auto-fit） | 五列对齐生效（对齐下限即 768px） |
| < 768px（含 375px 验收档） | 单列，卡片完整可见 | 两组纵向堆叠 | **降级**为窄屏整齐布局（五字段逐行堆叠，同类字段位置仍跨行一致），不溢出、不截断 |
| ≤ 640px | 教师卡片头纵向堆叠：照片在上、姓名/职称/方向在下（既有行为，保持） | 同上 | 同上 |

GitHub↗ / Homepage↗ 标签（对应字段非空时）在上述各档均不溢出：≥768px 集中于毕业生行链接列（§2），<768px 随行内流动；学生条目标签紧随姓名。

## 2. 对齐规则（Graduates，≥768px）

- 同类字段位置在所有行完全一致——混合对齐口径（2026-10-12 第三轮用户裁定）：第 1 列姓名、第 2 列学位、第 3 列毕业年份左对齐（起始位置跨行一致）；第 4 列去向居中对齐（各行中心点在同一直线上，左右留较大间距——部分去向名称较长）；第 5 列链接标签右对齐（结束位置跨行一致、贴行右缘 padding）。
- 第 1、2、3、5 列为内容无关的固定宽度（按最宽实际内容 + 余量：姓名 ≤4 汉字、学位 `Master`、年份 4 位数字、链接列按 `Homepage↗ GitHub↗` 最坏组合），第 4 列 `minmax(0, 1fr)` 弹性吸收剩余宽度并允许长去向在列内换行；列表满宽（不按内容收缩）、行左右 padding 对称（姓名距列表左缘＝链接标签距列表右缘）、字段间 column-gap 适当加大（2026-10-12 第三轮裁定）。
- `year` 缺失的行：第 3 列**留空占位**（学位照常显示于第 2 列），不影响其他行对齐，无多余分隔符；该行按 §2' 排在列表最后。
- 去向文字过长：在第 4 列内换行，不溢出容器、不破坏其他列位置。
- **链接列**（FR-011）：集中放置毕业生外链标签——`Homepage↗`（`url` 非空）与 `GitHub↗`（`github` 非空）并列；对应字段为空的行不渲染相应标签、链接列保留空占位（不渲染占位文本或符号）。标签为纯文本链接，复用既有 `Homepage ↗` / `GitHub ↗` 模式与色板。
- <768px 降级布局：五个字段逐行堆叠（姓名 / 学位 / 毕业年份 / 去向 / 链接行），同类字段起始位置跨行一致；`year` 缺失的行年份行不渲染（不渲染占位文本或符号），链接行无标签则为空行不渲染；有标签的链接行右对齐（贴行右缘 padding），去向行保持左对齐（2026-10-12 第三轮裁定）。

## 2'. 渲染排序（FR-012，全视口一致）

Graduates 列表渲染顺序 MUST 为：毕业年份（`year`）降序 → 同年份内 PhD 在 Master 之前 → 无年份（`year` 为空）条目排在全部有年份条目之后（组内同样 PhD 在前）→ 同排序键保持数据文件相对顺序（稳定排序）。排序在渲染时完成，与 `graduates.json` 条目顺序无关。当前数据预期顺序：杨泽娴（2025·PhD）→ 佀庆一（2024·PhD）→ 刘源鑫（2021·Master）→ 谭宇彤、温哲（无年份组，保持数据顺序）。

## 3. 空白判定（四档验收视口）

设计意图（FR-004）：保持合理信息密度与视觉平衡——留白仅用于分组、层级、呼吸与聚焦；由固定尺寸、内容缺失或未自适应造成的大面积无意义空白视为缺陷。

适用范围（rev2 拓展）：Team 页内容区内的**所有内容容器**——含学生分组条目、教师卡片及其内部各子容器、Graduates 列表行、各区块与分组容器等，嵌套容器逐层适用；共享教师卡片组件在主页的实例随组件同规则判定，主页其余区域维持 §5 回归约束。豁免：页面主容器居中版式（max-width 1180px）在超宽屏两侧留出的版式边距属有意设计，不视为缺陷；导航栏、页脚等页面框架级元素不属于本特性改动范围。

判定口径（FR-004，分档）：视口 < 1280px 的各档（含 375 / 768 / 1024px），任一容器内最右内容元素右端至该容器右边缘的**连续空白**超过该容器宽度的 FR-004 比例阈值即不达标；视口 ≥ 1280px（超宽屏）时，连续空白超过 FR-004 像素阈值即不达标（固定像素口径，不随容器宽度放大）。分档阈值的具体数值以 spec FR-004 为唯一规范源，本契约引用不复述。

- 在读学生条目：行采用两端分布（姓名居左、`Since 年份` 与备注居右），两侧内容朝中间收拢（姓名自分组左缘内收、`Since`/备注自分组右缘内收；收拢量按四档视口实测校准）——两端分布为合规形态，中间间隙与收拢产生的两端空白同步纳入 FR-004 判定（分档阈值见 FR-004），任一超标同样不达标（T006）。
- 教师卡片：研究方向标签横向流式换行，填满卡片信息列；末行残余空白按上述分档口径实测验收（所在容器＝方向标签所在的研究方向信息列，即照片右侧 `.teacher-identity` 区域）。
- Graduates 列表行（rev2 纳入；2026-10-12 第三轮裁定后为满宽形态）：列表满宽铺满内容区（避免右侧无意义空白与因空间不足导致的文字换行）；有外链标签的行右端空白自链接列最右标签起算（标签右对齐后 ≈ 行右 padding）；无任何外链标签的行见下方豁免。
- 无年级（`grade` 为空）的学生条目：仅左侧姓名，不算违规。
- 无任何外链标签的毕业生行（`url` 与 `github` 均为空）：链接列空置属内容缺失（FR-011 规格要求），去向居中排布下的行右侧空白豁免 FR-004 判定（2026-10-12 用户裁定，类比无年级学生条目豁免）。
- **GitHub↗ / Homepage↗ 标签计入条目内容**（FR-010/FR-011 不破坏 FR-004）：学生条目标签属左簇（姓名后），中间间隙自左簇末端（含标签）起算；毕业生行标签在链接列内，右端空白自链接列最右标签（如有）或去向文字末端起算。

## 4. 溢出保证（全视口）

- 四档验收视口 375 / 768 / 1024 / ≥1280px 下，Team 页无横向滚动、无内容裁切（教师卡片右侧完整可见）。
- 教师网格最小列宽 MUST NOT 超过容器可用宽度（`min(420px, 100%)` 语义）；方向标签优先整标签换行、单标签超长时标签内文字换行（FR-005），MUST NOT 依赖 `nowrap` 防溢出。
- 布局破损判定沿用 001：元素重叠、文字截断、内容溢出容器、非预期换行（另含"内容横向超出页面（视口）宽度范围"）。

## 5. 共享组件回归范围（FR-009）

`TeacherCard.astro` 同时服务于 Team 页（detailed）与主页 Team 概览区块（compact）：

- compact 模式样式行为不变（方向标签本就横向换行）；
- 主页（`index.astro`）四档视口下 MUST 无新增布局破损（共享卡片实例同 §3 空白判定规则）；
- `StudentGroup.astro` 仅 Team 页使用，无外部回归面。

## 6. 不变量（本特性 MUST NOT 改变）

- 数据层改动仅限：`students` / `graduates` 新增可选 `github` 字段、学生既有 GitHub 链接 `url→github` 迁移、`graduates` 新增可选 `url` 字段与三条已核实主页取值（FR-006）；`teachers` 数据、其余字段定义与数据内容、构建配置、CI 流程零改动；
- 页面展示的信息集合：教师（照片/姓名/职称/方向/邮箱/主页/bio）与学生（姓名/Since/备注/个人主页链接）不变；学生新增 `GitHub↗` 标签（`github` 非空时，FR-010）、毕业生新增 `Homepage↗` / `GitHub↗` 标签集中于链接列（FR-011）；
- 视觉基调不变（色板、卡片风格、正文字号 ≥18px）；
- 零新增 JS 与运行时依赖。
