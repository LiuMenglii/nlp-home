# Quickstart: Team 页布局优化验证指南

**Date**: 2026-10-12（rev：纳入 GitHub 标签验证） | **Spec**: [spec.md](./spec.md) | **布局契约**: [contracts/team-layout.md](./contracts/team-layout.md)

模板/scoped CSS 改动 + 最小数据迁移（学生 4 条 GitHub 链接 `url→github`）；无新依赖、无新 JS。验证 = 机器门禁（check + build）+ 浏览器手动视口矩阵。"大片空白"判定的分档阈值以 spec FR-004 为唯一规范源，本文引用不复述具体数值。

## 前置条件

- Node.js ≥ 22，仓库根目录已 `npm install`
- 浏览器 DevTools 响应式模式（或等价的视口宽度调节）

## 启动

```bash
npm run dev        # http://localhost:4321/team/
```

构建产物验证（最终验收前执行一次）：

```bash
npm run check && npm run build && npm run preview
```

## 验证矩阵

对照布局契约 [team-layout.md](./contracts/team-layout.md) 的视口行为矩阵逐项核对。

### 1. 移动端缺陷修复（Story 1 / FR-001、FR-002）— 视口 375px 与 768px

1. 打开 `/team/`，Faculty 部分每张教师卡片**完整落在可视宽度内**：研究方向标签、邮箱、Homepage 链接均可见，右边缘无截断。
2. 整页从上到下（Faculty → PhD/Master → Graduates）无横向滚动条、无内容被裁切。
3. 布局破损检查（001 口径 + CHK009 扩展）：无元素重叠、文字截断、内容溢出容器、非预期换行、内容横向超出页面（视口）宽度范围。

### 2. Graduates 列对齐（Story 2 / FR-003）— 视口 ≥768px

1. 任意两行毕业生对比：姓名、学位·年份、去向三类字段的起始位置分别处于同一水平位置。
2. 无年份条目（谭宇彤、温哲）：仅显示 `Master`，仍占位于第 2 列，其他行对齐不受影响。
3. 长去向（"北京大学（攻读博士）"）：在第 3 列内正常换行，不溢出、不错位。
4. 视口调至 <768px：列表降级为紧凑流式布局，不溢出（同类字段位置仍跨行一致）。
5. 当前毕业生数据均无 `github` 值：全部行不渲染 `GitHub↗` 标签、无占位残留（如本地验证标签形态，可临时给某条加 `"github": "https://github.com/octocat"` 后核对：标签内联于去向文字后、不破坏三列对齐——验证后还原，`graduates.json` 最终零内容改动）。

### 3. 学生列表空白（Story 3 / FR-004）— 视口 375 / 768 / 1024 / ≥1280px

1. PhD Candidates / Master's Students 每行：姓名居左，`Since 年份`（及备注如有）贴合分组右缘——条目内容右端无大片空白，两端分布行中间间隙同步判定（分档阈值见 spec FR-004）。
2. 无年级条目（李江楠）：仅左侧姓名（及其 GitHub↗ 标签），行整齐不错位。

### 4. 教师卡片空白（Story 4 / FR-004）— 视口 375 / 768 / 1024 / ≥1280px

1. 每张卡片：研究方向标签横向流式排布（优先整标签换行，单标签超长时标签内文字换行），标签区域右侧无大片空白（分档阈值见 spec FR-004；所在区域＝研究方向信息列，即照片右侧 .teacher-identity）。
2. 教师无照片时（可临时注释 `photo` 字段于本地验证）：卡片头排布正常，无异常空白或错位。

### 5. GitHub 标签（FR-010 / SC-006）— 视口 375 / 768 / 1024 / ≥1280px

1. 带 GitHub 链接的学生（李江楠、张瀚文、郑明钰、刘正宵）：姓名后显示 `GitHub↗` 标签，链接指向其 GitHub 个人页（新标签打开）；姓名本身不再可点击（`url` 已迁移置 null）。
2. 杨晨旭：无 `GitHub↗` 标签，姓名仍链接到个人主页（`url` 保留）。
3. 季慧山、刘曦雨、顾佴彬：无 `GitHub↗` 标签、无占位残留。
4. 标签不破坏所在条目的对齐（FR-003）与空白判定（FR-004）：学生行标签计入左簇、中间间隙仍达标；毕业生行（如本地临时加值验证）标签内联于去向列。
5. 375px 视口：标签随行内流动，不溢出、不截断。

### 6. 主页回归（FR-009）— 视口 375 / 768 / 1024 / ≥1280px

1. 打开 `/`（主页）：Team 概览区块的 compact 教师卡片在四档视口下无新增布局破损（对比改动前行为）。

### 7. 机器门禁

```bash
npm run check      # 类型 + schema 校验通过（含 github 字段）
npm run build      # 静态构建通过（CI 同口径）
```
