# Quickstart: Team 页多分辨率响应式布局验证指南

**Date**: 2026-10-15 | **Spec**: [spec.md](./spec.md) | **布局契约**: [contracts/team-responsive-layout.md](./contracts/team-responsive-layout.md) | **视图实体与数据映射**: [data-model.md](./data-model.md)

改动 = 表现层（`.astro` 模板 + scoped CSS 媒体查询）+ 毕业生数据合并（FR-011，仅 `graduates.json`）+ teachers 照片构建期校验（FR-016，仅 `content.config.ts`）。零新依赖、零新 JS。验证 = 机器门禁（`check` + `build`，含 FR-016 负向用例）+ 数据核对（对照 PPTX 映射表）+ 浏览器手动视口矩阵。断点数值以 spec FR-001 为唯一规范源，本文引用不复述。

## 前置条件

- Node.js ≥ 22，仓库根目录已 `npm install`
- 浏览器 DevTools 响应式模式（或等价的视口宽度调节）
- 《2026年招生介绍-G3.pptx》第 7 页「G3 组学生就业情况」表（数据核对参照，亦可对照 [data-model.md §1](./data-model.md) 目标状态表）

## 启动

```bash
npm run dev        # http://localhost:4321/team/  与  http://localhost:4321/
```

构建产物验证（最终验收前执行一次）：

```bash
npm run check && npm run build && npm run preview
```

## 验证矩阵

对照 [team-responsive-layout.md §1](./contracts/team-responsive-layout.md) 的视口行为矩阵逐项核对。验收档位：**≥1280 / 1279 / 1024 / 768 / 767 / 576 / 575 / 375px**（含三个边界切换验证点），另加 **320px** 边界；两页共检：`/team/` 与 `/`。

### 1. Faculty 教师网格分栏（US1 / FR-002 / SC-001）— 全档位

1. 打开 `/team/`，逐档统计 Faculty 每行卡片数量：≥1280px → **3**；1279px → **2**（紧下方即切换）；1024px → **2**；768px → **2**；767px → **1**（紧下方即切换）；576px → **1**；575px → **1**；375px → **1**；320px → **1**。
2. 同行卡片等宽（相邻卡片外缘宽度差 ≤1px）；除末行外无半满轨道/多余空轨道。
3. 打开 `/`（主页 Team 概览区块），在同一组档位核对列数与上表一致（US3 AS2 / FR-012）。

### 2. 教师卡片头部排布（US1 / FR-003 / CHK008 / CHK009 / SC-002）— 全档位

1. **≥576px 各档**（≥1280 / 1024 / 768 / 576px）：每张卡片头部为**照片在左、姓名/职称/研究方向在右**的横向排布；特别核对 **576px 与 767px 档**（原 ≤640px 会堆叠，本次 MUST 保持横向）。
2. **<576px 档**（575 / 375 / 320px）：卡片头部**照片水平居中在卡片内容区上方**；其下**姓名与职称同行**（姓名居左、**职称右对齐**）；**研究方向标签**紧随该行之下、标签区域最大宽度 = 卡片内容区宽度（**占内容整宽**）、**左对齐**。
3. 缺照片边缘用例：可临时将某老师 `photo` 置空于本地复验（验证后还原）——头部排布正常、无错位。

### 3. 研究方向标签收纳（US1 / FR-004）— 档位 ≥1280 / 576 / 375 / 320px

1. 常规标签组合：优先**整标签换行**（标签之间断行，标签内文字不断开）。
2. 超长单标签（如临时给某老师加一条超长方向名复验，验证后还原）：仅当单个标签自身宽度超过可用行宽时，**在该标签内换行**收纳。
3. 任一档位：标签不溢出卡片、不截断、不引发横向滚动。

### 4. Graduates 三段式（US2 / FR-006 / CHK010 / FR-008 / SC-004）— 档位 375 / 320px（<768px）

对每个毕业生条目核对（合并后共 14 条，条目集见 [data-model.md §1](./data-model.md)）：

1. **第 1 行**：左侧姓名；右侧**自右向左依次为年份与学位**——年份（如 `2025`）**右对齐贴行右缘**且其**容器宽度与年份数字等宽**（DevTools 检查 `.grad-year` 盒宽 ≈ 数字宽）；学位（`PhD`/`Master`）居年份左侧、**与年份之间隔一个空格**、**学位文字右对齐**。
2. **第 2 行**：去向，**左对齐**（不再居中）。
3. **第 3 行**：外链标签（佀庆一 / 杨泽娴 / 刘源鑫的 `Homepage↗`）**左对齐**（取代 002 窄屏右对齐）。
4. **无年份条目**（9 条匿名新条目 + 谭宇彤、温哲）：第 1 行右侧**仅展示学位**（右对齐贴行右缘），无年份占位、无多余分隔符或符号。
5. **无链接条目**（9 条匿名新条目 + 谭宇彤、温哲）：不渲染第 3 行，无空行残留。
6. 长去向（华为天才少年 → 京东大模型 / 北京大学 → 小米mimo 等）：在去向行内正常换行，不溢出、不破坏三行左起点。

### 5. 跨区块姓名列对齐（US2 / FR-007 / CHK035 / SC-004）— 档位 576 / 375 / 320px

1. 两个列表条目的左右内边距已统一收窄为 **24px**（左右对称；毕业生与在读学生两处一起改）。
2. 在 <768px 档对比某毕业生姓名与在读学生（PhD/Master 组）姓名的**左边缘**：DevTools 执行 `document.querySelector('.grad-name').getBoundingClientRect().left` 与学生姓名对应值，**差值 ≤ 1px**（目测为同一条竖直线）。
3. 576px 档同时复核学生分组仍为自适应两列/堆叠、姓名左起点不因本次改动漂移。

### 6. 桌面零回归（US2 AS5 / FR-009 / SC-005）— 档位 ≥768 / 1024 / ≥1280px

1. Graduates 维持**五列混合对齐**：姓名 / 学位 / 毕业年份左对齐、去向居中、链接列标签右对齐贴行右缘；跨行同类字段位置一致（含年份为空行的留空占位）。行内距由 44px 收窄为 24px 属**预期变更**（FR-007），其余形态不得回归。
2. 在读学生两端分布、学生 `GitHub↗` 标签不变；毕业生顺序按既有排序算法输出（年份降序 → 无年份最后 → 同组 PhD 在 Master 前 → 数组序 tiebreak），不再逐一枚举，核对以该算法对 14 条数据的实际输出为准（含保留的 `year=null` 条目 谭宇彤、温哲）。

### 7. 毕业生数据核对（FR-011 / SC-008）

1. 对照《2026年招生介绍-G3.pptx》就业情况表（14 行）与 [data-model.md §1](./data-model.md) 目标状态表核对 `src/data/graduates.json`：共 **14 条**；重叠 5 条仅 `destination` 更新（如佀庆一 → 华为天才少年 → 京东大模型、刘源鑫 → 北京大学 → 小米mimo，完整取值以 data-model 表为准）、`year`/`url` 保留原值；新增 9 条 `name` 用 PPTX 原文、`degree` 类型映射正确、`year` 为 null、无 `url`/`github`；去向「->」已规范化为「 → 」（箭头前后各补一个空格）。
2. `git diff` 核对数据改动范围：数据/schema 文件中**仅** `graduates.json`（内容）与 `content.config.ts`（teachers photo 校验）有改动，其余（teachers / students / publications / gallery / site、schema 字段定义）diff 为空。

### 8. 构建期照片校验（FR-016 / SC-009）

1. 临时将 `src/data/teachers.json` 某教师 `photo` 改为不存在的文件（如 `/teachers/missing.svg`），执行 `npm run build` → 构建**报错并中断**，报错信息能定位到教师与缺失路径；验证后还原，构建恢复通过。
2. （可选）临时将 `photo` 置空 → 构建照常通过（缺照片为合法状态），验证后还原。

### 9. 跨档无破损与主页回归（US3 / FR-010 / FR-012 / SC-003 / SC-006）— 全档位

1. 在 ≥1280 / 1279 / 1024 / 768 / 767 / 576 / 575 / 375 / 320px 浏览 `/team/` 全部区块（Faculty、PhD/Master、Graduates）与 `/` 教师区块：无元素重叠、文字截断、内容溢出容器、非预期换行、内容横向超出视口宽度；**无横向滚动条**（页面底部不出现水平滚动条、整页在屏幕宽度内完整显示）。
2. 主页教师卡片随共享组件同步呈现 §2 的头部排布，主页无新的布局破损。

### 10. 机器门禁（FR-014 / SC-007）

```bash
npm run check      # 类型 + schema 校验通过（graduates 新条目落入既有 schema）
npm run build      # 静态构建通过（含 FR-016 照片校验；CI 同口径）
```
