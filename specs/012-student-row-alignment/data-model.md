## 2. 视图实体

### 2.1 `StudentRow`（行）

| 列 | 来源 | 存在条件 | 渲染约束（本特性后） |
| --- | --- | --- | --- |
| 第 1 列 `name` | `student.name` | 恒存在 | 列宽固定 3.5em（63px），列内居左；纯文本、非链接；超长在列内换行；竖排态居第 1 行左侧 |
| 第 2 列 `since` | `"Since " + student.grade` | `grade` 非空 | 列宽固定 5em（90px）或 5.5em（99px，见 FR-011），列内居中；单行；字号 18px 不变；无年级不渲染元素，但列宽保留 |
| 第 3 列 `link` | `url` → `github` → `scholar` 第一个非空 | 三者至少一个非空 | 列宽固定 6.5em（117px），列内居右，右缘贴行内容右缘；标签单行；竖排态独占第 2 行并右对齐；无链接不渲染元素，但列宽保留 |

三列 MUST 使用同一套宽度；5em 与 5.5em MUST NOT 在同一分组内混用。

### 2.2 `RowLine`（行内几何）

- 记 `W` = 行内容区宽（`li` 边框盒扣除左右各 24px 内距），`N = 63px`、`S = 90px` 或 `99px`、`L = 117px`，列间空白 `g`。
- 横向态（≥480px）三轨：`3.5em` / `5em`（或 `5.5em`）/ `6.5em`，`column-gap: 0`、`justify-content: space-between`。
- 唯一几何状态（推导见 [research.md R2](./research.md)）：
  - `g = (W − N − S − L) / 2`；两侧空白相等，MUST ≥8px。
  - Since 列左缘 = `N + g`，Since 中心 = `N + g + S/2` = `W/2 − 27px`。
  - 链接列右缘 = `W`；姓名列左缘 = `0`（相对行内容区）。
- 不存在第二状态：固定列宽下不会发生列间挤压，011 的碰撞夹取已取消；27px 偏左是等隙的定义结果。

### 2.3 `StudentList`（分组区域）

- 结构：唯一 `<h3>` + `.phd-columns` / `.master-columns` 包装层 + 1–2 个 `<ul>`；条数与切分沿用 011，零改动。
- 三种视觉形态由 CSS 媒体查询切换：≥768px 两栏横向、480–767px 单栏横向、≤479px 单栏竖排。

## 3. 状态与转换

| 状态 | 触发条件 | 行内布局（本特性后） |
| --- | --- | --- |
| 两栏横向 | 视口 ≥768px 且 `columns.length === 2` | `W = (内容区宽 − 32) / 2 − 48`；固定三列 + 等隙；Since 中心在行中点左侧 27px；链接右缘贴齐 |
| 两栏横向·单条 | 视口 ≥768px 且 `columns.length === 1`（n=1） | 与单栏横向相同的固定三列，行宽 = 内容区宽 − 48 |
| 单栏横向 | 480px ≤ 视口 < 768px | `W = 内容区宽 − 48`（481px 档 385px、480px 档 400px）；固定三列 + 等隙；Since 中心同样偏左 27px |
| 单栏竖排 | 视口 <480px | flex 两行：第 1 行姓名左对齐 + Since 右对齐；第 2 行链接（若有）独占整行且右对齐；无链接不渲染第 2 行 |
| 空分组 | `rows.length === 0` | 沿用既有 "…coming soon." 占位；不渲染网格行 |

状态切换为纯 CSS，不依赖 JS；同一份 DOM 同时承载三种状态。

## 4. 缺失字段矩阵

| 姓名 | 年级 | 链接 | 横向态（≥480px） | 竖排态（<480px） |
| --- | --- | --- | --- | --- |
| 有 | 有 | 有 | 三列齐全；Since 在列内居中（行中点左 27px）；链接贴右缘 | 第 1 行姓名 + Since 右对齐；第 2 行链接右对齐 |
| 有 | 有 | 无 | 第 3 列保留 117px 空位；Since 位置与有链接行一致；无占位 | 仅 1 行；无空链接行 |
| 有 | 无 | 有 | 第 2 列保留 90 / 99px 空位；姓名与链接位置不变；无 "Since" 占位 | 第 1 行仅姓名；第 2 行链接右对齐 |
| 有 | 无 | 无 | 第 2、3 列均保留宽度；不渲染占位 | 仅 1 行 |

当前数据无「缺年级」实例；本特性不新增该场景的渲染分支，仅保证既有条件渲染在固定三列下不留占位、不移动其他元素。

## 5. 不变量

- **INV-1 数据零改动**：`src/data/students.json`、`graduates.json`、students schema 逐字节不变；30 条记录各渲染一次，0 丢失、0 重复、0 改写；排序与切分沿用 011（年级升序、`ceil(n/2)`）。
- **INV-2 DOM 零改动**：行内仍为 `span.student-name` + 可选 `span.grade` + 可选 `a.member-link`，顺序不变；无表头、无占位、无隐藏文本、姓名不可点击；结构保持 `ul` / `li`，不得改为 `<table>` 或添加表格语义；`.phd-columns` / `.master-columns` 类名与两个 `<ul>` 结构不变。
- **INV-3 固定列宽**：≥480px 每行实际轨道宽恒为 `63px / 90px（或 99px）/ 117px`，与姓名长短、链接有无、标签宽窄无关；同一分组所有行一致；5em 与 5.5em 不混用。
- **INV-4 等隙**：两侧列间空白 `g = (W − N − S − L)/2` 相等（偏差 ≤1px），且 `g ≥ 8px`；Since 中心在行内容区中点左侧 27px（±1px）；同一栏内所有行 Since 中心极差 ≤1px。
- **INV-5 空列保留**：缺链接时第 3 列仍占 117px、缺年级时第 2 列仍占 90 / 99px；不渲染占位、破折号或隐藏文本；其余元素位置不变。
- **INV-6 无夹取**：Since 位置 MUST NOT 因链接存在或标签宽窄移动；三列 MUST NOT 相互重叠；页面无横向滚动。
- **INV-7 贴边**：姓名左缘与行内容区左缘偏差 ≤1px；链接右缘与行内容区右缘偏差 ≤1px；链接标签单行。
- **INV-8 竖排**：<480px 第 1 行姓名居左、Since 右缘与行内容右缘偏差 ≤1px；有链接时第 2 行独占整行、右缘与第 1 行右缘偏差 ≤1px；无链接时不渲染第 2 行。
- **INV-9 结构不变**：≥768px 两栏、32px 栏距、各栏条数（PhD 10 + 9、Master's 6 + 5）、分组标题、名单顺序不变；断点仍为 768px / 480px。
- **INV-10 收纳**：超长姓名在姓名列内换行，不越入 Since 列、不撑宽行；Since 与链接标签单行；页面无横向滚动、无元素越界。
- **INV-11 字号与视觉基调**：Since / 姓名 / 链接计算字号均 18px，分组标题 20px；配色、字体族、分隔线、箭头与 hover 行为不变。
- **INV-12 范围隔离**：仅 `src/components/StudentGroup.astro` 的 scoped CSS 改动；`team.astro`、`global.css`、`content.config.ts`、数据文件、Graduates、Faculty、其他页面与依赖零改动。
- **INV-13 无破损**：十一档视口中元素重叠、文字截断、内容溢出、非预期换行、页面横向滚动计数均为 0；不以 `overflow-x: hidden` 掩盖。
