# 新闻 Markdown 编辑指南

本指南面向负责更新新闻的维护者，说明新闻详情页可用的三种重点控件（高亮块、BibTeX 引用块、表格块）与新闻配图的写法、限制和排错方法。所有内容都写在 `src/content/news/` 下的 `.md` 文件里，**不需要改任何组件或页面代码**。支持子目录：详情页 URL 由相对路径决定，例如 `src/content/news/lab-notes/probe.md` 发布为 `/news/lab-notes/probe/`。

> 控件只在新闻详情页（`/news/<相对路径>/`）生效；新闻列表、首页、Team、Publications 页面不会渲染这些结构。

## 1. 高亮块

用于强调关键结论、洞察或对比观点。全文建议 2–3 个，放在相关段落之后，不要用来装饰短句。

### 带标题

````markdown
:::highlight[一句话结论]
这里写需要强调的正文，可以包含 **加粗**、*斜体*、`行内代码`、
[链接](https://example.com)、列表、引用、代码块和图片。
:::
````

### 不带标题

````markdown
:::highlight
没有标题时不会出现空标题行，左侧仍保留 4px 强调竖线与底色。
:::
````

`:::highlight[]` 同样视为无标题。

### 支持的内容

段落、加粗、斜体、行内代码、链接、列表、引用、代码块、图片、普通 Markdown 表格都可以写在里面。里面的表格按普通表格渲染，不会自动获得表格块的横向滚动样式。

### 限制

- **结尾 `:::` 不能省**，否则构建失败并提示文件与行号。
- 不支持在高亮块里再嵌套一个 `:::highlight`；同名嵌套会降级为普通内容并输出 warning。
- 只有命令和结尾、没有任何内容的空块会被整块移除，并输出 warning；`---` 分隔线算可见内容，会保留。
- 不建议把高亮块写进列表项或引用块内部，只放在正文顶层。

## 2. BibTeX 引用块

用于给出论文的标准引用，读者可一键复制。

### 模板

````markdown
```bibtex
@misc{yang2026rlsd,
  title         = {{Self-Distilled RLVR}},
  author        = {Chenxu Yang and Chuanyu Qin and Qingyi Si},
  year          = {2026},
  eprint        = {2604.03128},
  archivePrefix = {arXiv},
  primaryClass  = {cs.LG},
  url           = {https://arxiv.org/abs/2604.03128}
}
```
````

- 语言标记**必须是小写 `bibtex`**。写成 `BibTeX`、`bib` 等非小写标记会让构建失败，并提示改成小写。
- 标记末尾多写的空格会被 Markdown 解析器裁掉：`bibtex `（`bibtex` 后带尾随空格）仍按合法 `bibtex` 渲染，不会报错。
- 缩进、换行、空格、花括号都会逐字保留，插件不格式化、不重排。
- 内容按纯文本显示；字段里若需要 `&`、`%`，按 LaTeX 规则写成 `\&`、`\%`。
- 长行只在代码块内部横向滚动，不会撑宽页面。
- 复制按钮默认在无 JavaScript 时隐藏；启用脚本后显示为 32×32 图标按钮，复制成功显示绿色对勾与“已复制”，失败显示红色叉号与“复制失败，请手动选择”，约 2 秒复位。
- 空代码块会保留空外观、不生成按钮，并输出 warning。

### 与普通代码块的边界

只有语言标记恰好为小写 `bibtex` 的围栏代码块才会变成引用块。标记为 `js`、`text` 等普通代码块保持原有渲染，不会有工具栏和复制按钮。若要展示一段 BibTeX 示例但**不**希望出现复制按钮，可把标记改成 `text`。

## 3. 表格块

用于横向对比。表格是真实 HTML `<table>`，可选中、可检索；窄屏下只在自身容器内横向滚动。

### 带标题

````markdown
:::table[表 1：三篇论文的定位对比]
| 维度 | 论文 A | 论文 B |
| --- | --- | --- |
| 教师信号来源 | …… | …… |
| 核心代价 | …… | …… |

:::
````

### 不带标题

````markdown
:::table
| 列一 | 列二 |
| --- | --- |
| A | B |

:::
````

`:::table[]` 同样视为无标题，不会生成空图注。

### 规则与限制

- 容器内必须是一至多张标准 Markdown 表格；没有表格时容器被移除、正文保留，并输出 warning。
- **表格最后一行之后、结尾 `:::` 之前建议留一个空行**。不留空行时，`:::` 可能被解析为表格的最后一行；插件会自动删除该行并输出 warning，但建议一次写对。
- 一个容器里有多张表时，每张表各自生成一个独立图注容器，**只有第一张表带图注**；需要每张表都有标题时，请分别使用独立的 `:::table[标题]` 容器。
- 结尾 `:::` 不能省，未闭合会让构建失败。
- **只建议放在正文顶层**：不要把 `:::table` 写进列表项、引用块或高亮块内部。嵌套语境下解析器可能不按预期识别容器，或生成不符合预期的结构；修复方式是把整个表格块移到这些嵌套结构之外，与高亮块保持一致。
- 表格不会转成图片，也没有灯箱；横向滚动容器可 Tab 聚焦，用方向键滚动。

### 与普通表格的边界

没有包在 `:::table` 里的标准 Markdown 表格保持普通渲染，不会获得 `.news-table` 样式与滚动容器。只有需要可选图注与窄屏滚动容器时才使用表格块。

## 4. 新闻配图

图片必须与 `.md` 文件放在同一目录（该目录可以是 `src/content/news/` 的任意子目录），用相对文件名引用；**不允许外链图片**，也不要使用其他文章的配图。

### 写法

````markdown
[![RLSD 方法框架图：以参考解答构造教师分布，并按 verifier 信号调整 token 权重](rlsd-method.png)](https://arxiv.org/abs/2604.03128)

图源：*Self-Distilled RLVR*（[arXiv:2604.03128](https://arxiv.org/abs/2604.03128)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）；图片未修改，仅按页面宽度缩放。
````

### 要求

- **文件名**：小写字母、数字、连字符，如 `rlsd-method.png`；与 Markdown 同目录。
- **替代文本（alt）**：用一句中文说明图展示的方法或流程，不要写“图 1”或逐字翻译图内标签。
- **点击行为**：用 `[![alt](图片)](论文链接)` 包裹图片，点击图片会在新标签页打开论文公开页；图注中的论文链接也使用 arXiv 地址。
- **图注**：紧随图片的普通段落，不是 `<figcaption>`。必须包含论文标题、论文公开链接、`CC BY 4.0` 许可链接，以及“图片未修改，仅按页面宽度缩放”声明。
- **尺寸**：页面按正文内容宽度展示。推荐源图宽度不超过正文内容宽度（桌面容器约 1132px）；如需适配 2 倍屏，可保留约 2264px 宽的版本，但必须同时满足下面的体积限制。高度按原图比例保留，不裁切、不拉伸。
- **超宽图**：宽度超过约 2264px 的截图或导出图，先等比缩放到该范围再入库，避免无谓体积。
- **体积**：单张 ≤500KB；图片按原始比例缩放，不放大超过固有尺寸。
- **缺失即失败**：图片文件不存在时构建直接失败并指出文件名，不会上线破图。

## 5. 诊断信息对照

构建时出现以下提示，按“处理”一列修改即可。

| 输入 | 级别 | 构建结果 | 处理 |
| --- | --- | --- | --- |
| `:::highlight` / `:::table` 缺少结尾 `:::` | 硬错误 | 失败 | 补上结尾 `:::` |
| `BibTeX`、`bib` 等非小写标记 | 硬错误 | 失败 | 改成小写 `bibtex` |
| 图片文件不存在 | 硬错误（Astro） | 失败 | 把图片放到对应 `.md` 的同目录，核对文件名 |
| 高亮块为空（只有命令与结尾） | 受控 warning | 继续 | 补充内容或删除整块 |
| BibTeX 块为空 | 受控 warning | 继续 | 补充条目或删除代码块 |
| 表格块内没有表格 | 受控 warning | 继续 | 放入标准 Markdown 表格 |
| 表格块内混有段落、列表等非表格内容 | 受控 warning | 继续 | 只把表格放进容器，其余内容移到容器外（会按普通 Markdown 保留） |
| 未知容器 `:::foo` | 受控 warning | 继续 | 改成 `highlight` / `table` 或删除命令 |
| 同名高亮块嵌套 | 受控 warning | 继续 | 拆成两个平行的高亮块 |
| 表格结尾 `:::` 前没留空行 | 受控 warning | 继续 | 在结尾前加一个空行 |

warning 不会中断构建，但会输出 `[news-widgets] 文件:行号`，请按位置修正；不要忽略新增 warning。

## 6. 常见错误排查

1. **高亮块/表格块“吞掉”了后面的正文**：通常是漏写结尾 `:::`，检查命令是否成对。
2. **BibTeX 块没有工具栏/复制按钮**：检查语言标记是否恰好是小写 `bibtex`；`BibTeX` 会直接报错，`text` 则按普通代码块处理。
3. **表格最后多出一行 `:::` 或表格缺了一行**：在表格与结尾 `:::` 之间补一个空行。
4. **图片不显示、构建报 ImageNotFound**：图片必须与 Markdown 同目录、文件名大小写一致；先放图片再引用。
5. **高亮块里出现多余的 `:::` 文本**：不要嵌套同名高亮块；需要并排强调时写两个独立块。

## 7. 本地验证

```bash
npm run dev      # 本地预览，默认 http://localhost:4321/nlp-home/
npm run build    # 完整构建，校验内容、图片与控件语法
npm run check    # 类型与 Astro 语法检查
```

发布前至少检查：

- 四种视口宽度：375 / 768 / 1024 / ≥1280px，另加 320px；
- 浏览器 200% 文字缩放；
- 页面整体没有横向滚动条（表格与 BibTeX 只在各自容器内滚动）；
- 用 Tab 键能依次聚焦复制按钮、BibTeX 代码块、表格滚动容器，焦点外框可见；
- 关闭 JavaScript 后，复制按钮隐藏、正文与代码块完整可读；
- 点击配图与图注中的论文链接，均在新标签页打开论文页。

## 8. 五个最容易踩的点

1. 结尾 `:::` 不能省。
2. BibTeX 语言标记必须全小写。
3. 表格结尾 `:::` 前建议留空行。
4. 高亮块不要嵌套同名高亮块。
5. 配图必须与 Markdown 同目录并用相对文件名引用。
